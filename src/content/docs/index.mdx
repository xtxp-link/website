## Four named parts

<CardGrid>
  <Card title="XTXP: the protocol" icon="document">
    The specification every node obeys. **The Math** defines how concurrent edits merge. **The Wire** defines how they travel.
  </Card>
  <Card title="Xmesh: the engine" icon="setting">
    The CRDT engine that resolves concurrent edits on an XML tree. A C++20 reference implementation, plus a pure Elixir port held to the same test vectors.
  </Card>
  <Card title="MUPPET: the executor" icon="pencil">
    Multi User Progressive Patch Execution Tree. Client-side Xmesh, embedded in Inkscape, in the browser via Wasm, or on a server for no-JS users. It owns all views.
  </Card>
  <Card title="Erlang Trackers: the routing layer" icon="random">
    One lightweight Erlang process per document branch. Trackers hold history, keyframes and presence, and route patches between nodes.
  </Card>
</CardGrid>
