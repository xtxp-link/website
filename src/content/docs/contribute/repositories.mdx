Everything is developed in the open, under the [`xtxp-link`](https://github.com/xtxp-link) organisation on GitHub. Repositories are public by default.

| Repository | What it holds | Status |
| --- | --- | --- |
| [`website`](https://github.com/xtxp-link/website) | This specification and site, plus plans and handovers in `docs/plans/` | Live |
| `xtxp-rs` | The Rust reference implementation: Xmesh, the wire, the host, CLI peers, feature files and test vectors | Coming with [M1](/build/milestones/) |
| `inkscape` | The [Inkscape fork](/build/inkscape-fork/), linking Xmesh as a native peer | Coming with [M2](/build/milestones/) |

Changes to behaviour start here, in the spec, and code follows in the other repositories. This layout is set for the first milestones and is likely to be tidied and restructured as the project grows.

To argue with the design, start with the [open questions](/discussion/open-questions/) and the [decision log](/discussion/decisions/).
